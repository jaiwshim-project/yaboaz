1. 현장 탐색의 정의와 위치

현장 탐색은 단순한 방문이나 인터뷰가 아닙니다. 실제 업무가 일어나는 장소·시스템·화면·문서·사람의 행동을 관찰하여 공식 프로세스와 실제 프로세스의 차이를 발견하는 활동입니다.

사람누가 일하고 판단하며 실행하는가?
업무어떤 순서와 조건으로 진행되는가?
정보어떤 자료와 화면을 보고 판단하는가?
실행어디에서 지연·반복·예외·우회가 발생하는가?

현장 탐색은 문제를 보는 활동이 아니라 실행 가능한 구조로 바꿀 수 있는 증거를 발견하는 활동입니다.

2. 현장 탐색의 핵심 산출물

현장 탐색 보고서관찰한 업무흐름, 문제 신호, 병목과 예외를 정리합니다.
업무 동선 지도사람이 움직이는 경로와 정보 흐름을 표시합니다.
공식·실제 비교표매뉴얼과 실제 행동의 차이를 기록합니다.
현장 신호 목록지연·반복·불일치·미사용 기능을 모읍니다.
병목·우회업무 목록수기·엑셀·메신저·전화 처리 지점을 찾습니다.
이해관계자 지도실제 실행자·승인자·데이터 소유자를 파악합니다.
Evidence 카드관찰 사실을 출처·시점과 함께 기록합니다.
구조화 후보후속 질문·온톨로지·AI 판단·MVP 후보를 도출합니다.
현장 행동 → 반복 패턴 → 문제 신호 → Evidence → 구조화 후보

3. 현장 탐색 8단계

01

탐색 목적 확인

고객이 말한 문제의 실제 발생 위치, 사용자, 판단과 예외를 확인할 목적을 정합니다.

02

관찰 범위 설정

사람·업무·데이터·시스템·공간의 범위를 정하고 이번 탐색에서 제외할 영역을 명시합니다.

03

방문 전 자료 검토

매뉴얼, 조직도, 화면, 양식, 로그, 민원, KPI와 보안정책을 검토해 현장 확인 질문을 만듭니다.

04

업무 동선 관찰

사람의 이동, 정보 전달, 입력 위치, 승인 지점, 대기와 반복, 비공식 도구 사용을 기록합니다.

05

공식·실제 프로세스 비교

매뉴얼에 있지만 하지 않는 일, 실제로 하지만 기록되지 않는 일, 우회되는 승인과 예외를 찾습니다.

06

병목·예외·우회 발견

정보·승인·시스템·데이터·역할·공간·판단·커뮤니케이션 병목을 분류합니다.

07

Evidence 카드 작성

관찰 사실·수치·시점·장소·도구·관련 문제를 증거 단위로 등록합니다.

08

후속 질문과 구조화 후보 도출

맞춤 인터뷰 질문, 온톨로지 7요소, AI 판단 후보와 MVP 후보를 정리합니다.

10. FireNavi 적용 예시와 최종 완료 기준

관찰 상황

7층 복도 센서가 작동했지만 관제 화면에는 센서 ID만 표시되었습니다. 관리자는 전화로 위치를 확인했고, 전체 방송은 나갔지만 안전한 계단 안내가 없었습니다. 일부 입주자는 연기 확산 위험이 있는 계단으로 이동했습니다.

정보 병목센서 ID와 실제 공간 정보가 연결되지 않음
판단 병목위험구역과 안전경로 기준이 불명확함
실행 병목전체 방송만으로 개인별 경로가 없음
MVP 후보센서 위치 연결 → 위험경로 제외 → 관리자 승인 → 안내 발송
