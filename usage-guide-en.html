How to use the platform

YABOAZ is an execution platform for users with a valid access code. Follow these steps to get started.

1

Get an access code

Receive a 10-digit access code through one of the two issuance methods below.

2

Sign up

Enter your email, password, name, organization, phone number and access code.

3

Log in

Log in with the email and password you used during registration.

4

Run the 13 stages

Move from customer onboarding and field discovery to structure, execution, validation and assetization.

How to obtain an access code

An access code is a 10-digit code used to verify platform access. Each code can be used only once.

1. K-FDE training graduates

Graduates of the K-FDE training program can request an access code from the course operator or platform administrator.

  • Completion of the training program is verified.
  • An administrator issues a 10-digit access code.
  • Enter the code on the sign-up screen.

2. Access code purchasers

Users who purchase an access code receive it through the delivery method provided after the purchase is confirmed.

  • Purchase the access code and complete payment.
  • The 10-digit code is delivered to the purchaser.
  • Enter the code on the sign-up screen.
Do not share your access code. A code that has already been used or is invalid cannot be used for registration.

Start immediately after sign-up

After registration, log in and open Mission Management to begin the 13-stage execution flow. For help, contact the training operator or the organization that issued your access code.
